# ***gfdsss.com***

The source code for the [website of the Gfdssian people](https://gfdsss.com/) (Hailing from the widely renowned [r/gfdsss](https://www.reddit.com/r/gfdsss/))! At present, it remaineth heavily a work in progress, and ideas for its further making are most welcome.

Ideas are, indeed, most welcome even when not accompanied by any code. Moreover, a simpler means of contributing text for those less acquainted with the technical arts, or indeed anyone who would rather not meddle with code, is something we hope to devise in due course.

## A Word of Notice

For any new changes, one must first create a new branch from the `develop` branch and apply their changes therein; once the changes are to be deemed ready, a pull request may then be made for the branch to be merged into `develop`, as `main` is reserved for production.
